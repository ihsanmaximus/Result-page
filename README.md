# Ayyash Consulting

Website statis hasil ekspor dari Maximus.

## Cara memakai
Buka `index.html` di browser, atau unggah seluruh isi folder ini ke hosting statis.

## Isi
- `index.html` — halaman website
- `style.css` — gaya (tanpa dependensi framework)
- `script.js` — navigasi hamburger dan interaksi
- `assets/images/` — gambar yang dipakai section (4 file)

## Section yang diekspor
- Navbar
- Hero
- Services
- About
- Portfolio
- Testimonials
- FAQ
- Contact
- Footer
